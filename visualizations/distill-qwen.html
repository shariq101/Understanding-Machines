Part XVI · 1.5B scale

What reasoning distillation moved.

Qwen2.5-Math-1.5B and DeepSeek-R1-Distill-Qwen-1.5B have the same 28 blocks, the same 1536-wide residual stream and the same twelve heads. Their parameter counts are not identical — 1543.7M against 1777.1M — because the distilled checkpoint unties its embedding and output matrices; depth and width are equal. The second is fine-tuned from the first with reasoning data generated by DeepSeek-R1. The actual R1 teacher is 671B and is not available here, so this page calls the Qwen checkpoint the reference and the DeepSeek checkpoint the distilled model — not a teacher and a compressed student. Both are taken apart with the same 476 mean-ablation conditions, the same ripple, and CKA computed separately for the residual stream, attention write and MLP write. Nothing runs in the browser.

Which reference layer each distilled layer resembles

Linear CKA between every distilled block and every reference block, over all non-pad token representations in the twelve-prompt bank. One means the two organize the same tokens identically up to an orthogonal transform; zero means no linear agreement. The outlined cell is the same-index reference layer for this equal-depth pair. A high diagonal value means distillation preserved the stage; an off-diagonal maximum is reported but is not treated as a layer shift, because the residual stream accumulates.

Does the match survive ablation?

CKA is measured on a clean pass; a functional correspondence should also predict where damage lands. For each distilled block, its twelve whole-block KL values are correlated with each reference block’s twelve, after removing each layer’s mean and each prompt’s mean so prompt difficulty and layer scale cannot manufacture agreement. This is an intervention fingerprint, not a causal identification: it asks whether two blocks fail on the same prompts, not whether one computes the other.

Which component carries it?

A whole-block fingerprint can hide two different failures: attention may stop routing the same way while the MLP still writes the same feature, or the reverse. This repeats the damage comparison separately for the attention write and the MLP write, and reports a permutation null — the best of all distilled–reference pairs after shuffling the prompt order. Below it, the best CKA partner is shown separately for the residual stream, the attention write and the MLP write.

Where the next tokens diverge

Both models complete the same twelve prompts. The bar is total variation between the two next-token distributions over the union of their top ten tokens; the words are each model’s own top choice. Small gaps mean the distillation preserved the output; large ones show where it did not.

The idea, and what it costs

Distillation replaces a hard target with a distribution. Hinton, Vinyals and Dean (2015) train the student on the teacher’s softened outputs — logits divided by a temperature T — so that the relative probabilities of wrong answers carry information a one-hot label throws away. The student is not fitted to the data alone; it is fitted to the teacher’s function on the data. DeepSeek-R1’s distilled checkpoints apply that idea with reasoning traces: the smaller dense model is trained on outputs generated by the much larger R1 model, not merely on the original pretraining corpus.

This pair is the same architecture at both ends. Qwen2.5-Math-1.5B has 28 blocks, 1536 hidden dimensions and twelve heads; DeepSeek-R1-Distill-Qwen-1.5B has the same 28, 1536 and twelve, and is fine-tuned from that Qwen base. The distilled checkpoint is larger in parameters (1777.1M against 1543.7M) because it does not tie embeddings and the output matrix; that is a vocabulary-and-head effect, not extra depth. Nothing is compressed. The question is therefore not what survived halving the depth but what the R1 distillation changed at each depth: whether the layer correspondence stays on the diagonal, whether attention and the MLP move together, and whether the damage profile follows the representation. That is a different question from the BERT and RoBERTa pages, and the page labels it that way.

Same depth, different training

In a depth-compressed student, a layer has to absorb the work of several teacher layers, so a monotone but non-identity CKA mapping is expected. Here every student block has a same-index reference block of the same width. A near-diagonal CKA matrix means the fine-tuning preserved the stage; a systematic off-diagonal shift means the reasoning training reorganized when a computation happens, even though the architecture did not change. Both are measurable, and neither is assumed from the initialization.

What CKA can and cannot say

Linear CKA (Kornblith et al., 2019) compares two representation matrices by the similarity of their Gram matrices. It is invariant to orthogonal transforms and isotropic scaling, but it is not invariant to arbitrary nonlinear remapping, and a high value does not prove that one layer computes the other’s function. Measuring it separately for the residual stream, the attention write and the MLP write asks whether the similarity lives in one component or only in their sum.

Attention and the MLP are different objects

Attention mixes information across positions; the MLP rewrites each position independently. Prior work finds heads with specialized roles (Voita et al., 2019) and feed-forward layers behaving like key-value memories (Geva et al., 2021). The ablation separates the concatenated attention write, each individual head, the MLP write, and the two layer norms, so the distilled model’s change can be read per component instead of as a single block number.

What this page measured, and what it did not

The intervention is mean ablation: a component’s write at every token position is replaced by its average over the prompt bank. The bank is twelve causal prompts, the readout is the next-token distribution at the final prompt token, and both models are the base checkpoints — no chat template, no chain-of-thought generation, no downstream fine-tuning. CKA is measured on the same prompts used for the ablations, so the correspondence and the intervention effects are not independent evidence. The actual R1 teacher is absent; this page compares the distilled checkpoint with its Qwen initialization, and no result here is a claim about R1 itself.

Method

Prompts. Twelve causal prefixes, read at the next token. Intervention. Mean ablation at every non-pad token position: the node still runs, but its write is replaced by its mean over the bank. Readout. KL divergence between the clean and ablated next-token distributions at the final prompt token, plus the probability of the clean top-1 and the top five tokens. Components. Concatenated attention write, each head separately, MLP write, input layer norm, post-attention layer norm, and the whole block (all heads plus MLP). Correspondence. Linear CKA over every non-pad token representation, on the clean pass, for the residual stream, attention write and MLP write. Hardware. One T4, float32.

Limits. Causal next-token readout, twelve prompts, one intervention family. Mean ablation removes input-specific signal but not the component itself, so a small KL does not mean the block is unnecessary — only that its average write is close to sufficient for these prompts. CKA compares geometry, not computation; the damage fingerprint is descriptive and its permutation null is reported on the page. The reference is the initialization, not the 671B R1 teacher, so this is not a teacher–student compression result.
