Part XVI · Vision distillation

What the smaller DeiT kept.

DeiT-base-distilled and DeiT-small-distilled have the same twelve ViT blocks, patch size 16 and 224-pixel input, but different widths and head counts. Both are published students of RegNetY-16GF, not of each other: the base is not the small model’s teacher, and neither checkpoint contains the RegNet weights. This page therefore calls them the reference and the distilled model, never teacher and student. It measures 336 mean-ablation conditions across the two — every head, attention write, MLP, layer norm and whole block — on twenty Imagenette images, two per class, plus ripple at the class token, CKA over the 196 patch tokens, and four attention/MLP cross-CKA matrices. The actual RegNetY-16GF teacher is now run on the same bank for output and pooled-feature checks; it is not retrained. Nothing runs in the browser.

The teacher, actually run

The missing leg was the teacher itself. RegNetY-16GF is loaded from the DeiT authors’ timm checkpoint regnety_160.deit_in1k on the same twenty images and compared with both DeiT checkpoints: ten-way candidate accuracy, full 1000-way and ten-way KL/TV, agreement, confidence, and linear CKA between its pooled feature and each student’s class token at every block. The teacher is not retrained, ablated, or used to identify a causal circuit. The CKA is an image-level check over only twenty images, with a permutation null for the best layer.

Which reference block each distilled block resembles

Linear CKA between every distilled block and every reference block, over the 196 patch-token representations in the twenty-image bank. One means the two organize the same patches identically up to an orthogonal transform; zero means no linear agreement. The pair has equal depth, so the outlined cell is the same-index reference layer. A high diagonal means the smaller model preserved the stage; an off-diagonal maximum is reported but is not treated as a layer shift, because the residual stream accumulates and adjacent ViT blocks are highly correlated.

Does the match survive ablation?

CKA is measured on a clean pass; a functional correspondence should also predict where damage lands. For each distilled block, its twenty whole-block KL values are correlated with each reference block’s twenty, after removing each layer’s mean and each image’s mean. This is an intervention fingerprint, not causal identification: it asks whether two blocks fail on the same images, not whether one computes the other.

Which component carries it?

A whole-block fingerprint can hide two different failures: attention may stop routing the same patches while the MLP still writes the same feature, or the reverse. This repeats the damage comparison separately for the attention write and the MLP write, with a permutation null over image order. Below it, the best CKA partner is shown separately for the residual stream, the attention write and the MLP write.

Which part of the reference was copied?

A layer match does not say whether the smaller model’s attention learned the larger model’s attention or its MLP. Four cross-component matrices answer that directly: distilled attention against reference attention, distilled attention against reference MLP, distilled MLP against reference attention, and distilled MLP against reference MLP. Each row lets a write choose either component at any depth. Same-kind wins support component-specific borrowing; cross-kind wins are the places where “the smaller model copied the larger one’s attention” is too simple. This is a sibling comparison — both copied RegNet, not each other — so nothing here identifies what either learned from the actual teacher.

Where the class bets diverge

Both models classify the same twenty images. The bar is total variation between the two 1000-way distributions over the union of their top ten labels; the labels are each model’s own top choice. Small gaps mean the smaller checkpoint preserved the output; large ones show where width and head count changed the bet. These are base checkpoints, so the labels are ImageNet classes and Imagenette is a ten-class subset — no fine-tuning accuracy is claimed.

The idea, and what it costs

DeiT distills a convolutional teacher into a vision transformer with a distillation token and a hard-label objective: the student sees the teacher’s predicted class as a target, in addition to the ground-truth label. Touvron et al. (2021) released checkpoints trained this way. Both models on this page are from that family, and both were distilled from RegNetY-16GF. They are not a compression pair: the small model was trained separately, with six heads and a 384-wide residual stream, rather than pruned from the base.

The comparison is therefore a scale check within one distillation recipe. It can show which computations survive when the student is made smaller, and whether the smaller model’s components remain closest to the same component of the larger one. The teacher check above adds the missing output and pooled-feature comparison, but a match between two students is still not evidence about what either learned from RegNet. The teacher is run for measurement, not retraining or circuit ablation.

Why component cross-CKA

Attention and the MLP are different objects. Attention mixes information across patches; the MLP rewrites each patch independently. A smaller student can preserve the larger model’s attention geometry while replacing its MLP with a different feature map, or the reverse. The four cross matrices make that choice visible. A distilled attention write whose best match is a reference MLP write is not evidence that attention copied attention, however high the number. The borrowing table reports both the winning kind and the winning depth, so a same-kind win at an unexpected depth is distinguishable from a cross-kind win.

What CKA can and cannot say

Linear CKA (Kornblith et al., 2019) compares two representation matrices by the similarity of their Gram matrices. It is invariant to orthogonal transforms and isotropic scaling, but not to arbitrary nonlinear remapping, and a high value does not prove that one layer computes the other’s function. Measuring it separately for the residual stream, the attention write and the MLP write asks whether the similarity lives in one component or only in their sum. The cross matrices go one step further, but they remain a clean-pass representation measurement; they do not establish a causal copy.

What this page measured, and what it did not

The intervention is mean ablation: a component’s write at every token position is replaced by its average over the twenty images. The readout is the 1000-way class distribution at the class token, and both models are the base checkpoints — no fine-tuning, no augmented test set, no downstream segmentation. CKA is measured on the same images used for the ablations, so the correspondence and the intervention effects are not independent evidence. The actual RegNetY-16GF teacher is run separately for output fidelity and an image-level feature CKA; it is not ablated or retrained, and the twenty images are two per class from a single Imagenette validation folder.

Bank stability. The original ten-image run gave attention 12/12 and MLP 8/12 same-kind, with the four cross-kind MLP wins at L5–L8; its same-index CKA ran from 0.94 to 0.42 and its mean top-10 TV was 0.066. Adding the second image per class leaves the 12/12 and 8/4 split and the L5–L8 crossover unchanged; CKA runs from 0.94 to 0.41 and mean TV is 0.071. The extra images come from the same Imagenette validation folder, so this is a bank-size check, not an independent dataset.

Method

Images. Twenty Imagenette 320 validation images, two per class, resized and normalized by each model’s processor. Intervention. Mean ablation at every non-pad token position: the node still runs, but its write is replaced by its mean over the bank. Readout. KL divergence between the clean and ablated 1000-way class distributions at the class token, plus the probability of the clean top-1 and the top five labels. Components. Concatenated attention write, each head separately (twelve in the base, six in the small), MLP write, both layer norms, and the whole block. Correspondence. Linear CKA over the 196 patch tokens, on the clean pass, for the residual stream, attention write, MLP write and the four attention/MLP cross pairs. Teacher check. RegNetY-16GF clean logits and pooled feature on the same twenty images; full/10-way KL and TV to each student, agreement, confidence, and image-level CKA against the student class token at every block with a 200-permutation null. Hardware. One T4, float32.

Limits. Twenty images, one intervention family, one checkpoint per scale. Mean ablation removes image-specific signal but not the component itself, so a small KL does not mean the block is unnecessary — only that its average write is close to sufficient for these images. CKA compares geometry, not computation; the damage fingerprint is descriptive and its permutation null is reported on the page. Both models are students of RegNetY-16GF; the teacher is run for output and pooled-feature checks, but not retrained or ablated, so this is still not a causal teacher–student attribution result.
