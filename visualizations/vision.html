The vision lab

Five ViT-family models read the same pictures. Pick one, ask what a single head or MLP contributes on its own, then choose a range of layers and see what removing it — or keeping only it — does to the answer.

For the four-view version — a clickable layer board, a damage cascade, every measured run, and all the deletion curves at once — open the ablation studio.

The atlas, one node at a time

Each cell is one attention head, or the layer's MLP, replaced by the write it produced for a different image. Rows are layers, columns are heads; the last column is the MLP.

The layer playground

Pick a range of layers and a direction. Every cell of the grid was measured on the same image bank, so the two handles select a result rather than compute one.

Ablate by hand

Click any head or MLP to replace it with the write it produced for a different image; click again to restore it. One node is a measurement, and so is a run of complete layers — the block grid has those. Any other set is a sum of separate measurements, and the panel tells you which of the three you are reading.

The circuit, kept and removed

ACDC kept the edges whose removal cost the most. Both directions are reported against random sets of the same size, because a circuit that does nothing also reports a number.

Where the circuit sits

Kept edges by sender and receiver. Row 0 is the token embedding; the last column is the output head.

What this page is. Nothing here runs a model in the browser. Every number is a measurement made once, on a GPU, over a fixed bank of images; the controls select among measured conditions. Where the measurement is missing — a sweep still running, a model that has no pixels to show — the panel says so instead of drawing a plausible line.
